# Code of Conduct

Zapiski Site Engine is maintained as a small, practical open-source project.

Please keep discussions:

- respectful and specific
- focused on the code, documentation, or user safety
- free of private production data, credentials, and personal user information

Do not post:

- API keys, passwords, tokens, or SSH keys
- production databases or user uploads
- private server inventory
- personal data from real users
- harassment, threats, or discriminatory language

The maintainer may edit, hide, or close issues and pull requests that put users,
operators, or private infrastructure at risk.
