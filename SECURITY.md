# Security Policy

Please do not open public issues with secrets, private logs, production URLs,
or user data.

If you find a vulnerability, email the maintainer or open a private GitHub
security advisory when available. Include a short description, affected files,
and a safe reproduction that does not expose real user data.

This public repository must not contain:

- tokens or API keys
- SSH keys
- production databases
- user uploads
- deployment inventory
- private server paths
