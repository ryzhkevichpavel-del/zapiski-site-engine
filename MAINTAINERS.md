# Maintainers

## Primary maintainer

- GitHub: [ryzhkevichpavel-del](https://github.com/ryzhkevichpavel-del)
- Role: primary maintainer

The primary maintainer is responsible for:

- reviewing issues and pull requests
- keeping private production data out of the public repository
- maintaining release notes and tags
- preserving security and privacy boundaries
- deciding whether optional bridge-related changes belong in the public engine

## Maintainer expectations

Maintainers should keep the project safe for small self-hosted operators:

- never request real user data in public issues
- never commit databases, uploads, keys, tokens, or server inventory
- prefer small, reviewable changes
- keep documentation practical and reproducible
- run the documented checks before release
